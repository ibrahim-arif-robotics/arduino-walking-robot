# Arduino-walking-robot
An arduino based 4 legged walking robot that uses a remote to control directon
## Components needed
An Arduino uno ,4 servo motors,an IR receiver, a remote, 4aa battery case , and a breadboard also i recommend a capacitor  
## What I Learned 
Controlling multiple servo motors with Arduino and interpreting IR remote signals combining hardware and software into a working robotic system 
## Future Improvements 
Improve walking stability and add more commands
